## 1. 身份与合规（2026-11-14）

**上游** `wingedpanther/openshelf`，GPL-3.0-**only**，单人项目 8 个 commit。
本项目是汉化 + 国内源 + 换品牌的衍生版。

GPL 原文核实后的结论（决定了后面所有命名行为）：

| 条款 | 要求 | 落地 |
|---|---|---|
| §5(a) | 显著声明修改 + 日期 | `README.md` 顶部声明块 + `NOTICE.md` |
| §5(b) | 显著声明按本许可证发布 | 同上 |
| §5(c) | 整体仍 GPL-3.0，不能换证 | `LICENSE` 原样 |
| §5(d) | 交互界面显示 Appropriate Legal Notices | 设置页「关于」→ `about_help` 中英文都写了「非官方衍生版 + 日期 + GPL-3.0」 |
| §6(d) | 分发 APK 须同渠道提供源码 | Releases 必须带源码 |
| §7(e) | 商标权不随 GPL 授予 | **必须改名换标**，不能继续叫 Open Shelf |

**定名**：用户 2026-11-14 16:07 定为 **OpenAPK TV**（英文），此前给过的中文候选（「开架」等）未采用。
定名后一次性完成技术标识脱钩：`namespace` / `applicationId` / 6 个 kt 的 package / 源码目录 /
`rootProject.name` / User-Agent / Manifest label / 22 处界面自称。

**保留不变的 11 处 "Open Shelf"**：全是来源说明性质（NOTICE 来源段、README 衍生声明、`about_help`）。
这不是遗漏，删了反而违反 §5(a)。

**图标**：用户提供 Gemini 生成的猫耳电视图（黑底白壳 + 四色象限）。
`art/generate_icons.py` 用 floodfill 从四角抠掉连通黑底（保住屏幕内深色边框，主体 bbox 不裁切），
生成 12 张：5 档 launcher + 5 档 banner（16:9 黑底 + 图标 + Geist「OpenAPK TV」，满足 TV-BN 要求横幅含应用名）+ 2 张 mark。

> TV 规范要点：launcher 基准 80dp（不是手机的 48dp），xxxhdpi 要 320×320；
> 1080p 主屏上 banner 实际只渲染 192×108，所以横幅里的字必须够大。

## 2. 技术选型

| 决策 | 理由 | 被否定的方案 |
|---|---|---|
| 不引入 Navigation / ViewModel / Room / Retrofit / Coil / Hilt | 8 个视图、8 个偏好键、2 类网络请求，全局 `object` 就是依赖图；加库会拉高 APK 体积与镜像可达性风险 | 标准分层架构（对这个体量是过度设计） |
| 用 `LocalDensity` 缩放实现设计坐标 | 1280×720 设计稿的像素值可直接写成 dp，比例在任意电视上一致 | `BoxWithConstraints` 里手动换算比例（每个视图都要乘系数，必错） |
| 焦点环自己画（`Modifier.ring`） | TV Material 的 Border+Glow 在浅色白卡上糊成一片；自制可显式留 `gap` 间隔，深浅两主题都清晰 | 用 `Surface` 的 focused 状态 |
| 语言切换不重建 Activity | `createConfigurationContext` 换 `Resources` + `rev++` 触发重绘，不闪屏、不丢状态 | `AppCompatDelegate.setApplicationLocales`（要引 appcompat）、`recreate()`（会白屏） |
| 镜像三级回退，原链兜底 | 实测 `gh-proxy.com` 174KB/s、`ghproxy.net` 96KB/s、`cdn.jsdelivr.net` 与 `raw.gitmirror.com` 已不可用；公共代理随时会挂 | 单一镜像硬编码、改数据源为 Gitee（等于重做上游未开源的抓取管线） |
| 默认「自动」按系统语言选源，而不是默认全走镜像 | 中文电视盒子大多在国内网络；英文系统多半在墙外，绕公共代理只会更慢。语言是「这台机器在哪」最省事的代理指标，用户又能随时在设置里钉死 | 默认全走镜像（海外用户白白变慢）、按 IP 探测（要联网、首启即超时、隐私上也不好解释） |
| 图片不用 Coil | 需要「候选 URL 逐个尝试 + 解码失败也算失败 + 首帧不闪」，自写 70 行即可 | Coil 自定义 Fetcher（依赖重、调试成本高） |
| 应用描述保持英文 | catalog 是上游生成管线产物，改了无法同步 | 机翻写回 catalog.json（污染数据源，不可逆） |

## 3. 界面演进（v1 → v9）

用户否定了六版才定稿，每次否定都指向同一个问题：**这不是电视**。

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | 左侧固定 rail + 全局状态条 + 双栏表单 | **否决**：「根本不像电视的设计」「还不如原版」——做成了网页控制台 |
| v2 | 回到原版 TV 骨架：顶栏胶囊 tab + 左大封面 hero + 横向卡带 + Leanback 设置 | 通过，被认为「骨架对了」 |
| v3 | 换 M3 for TV 视觉语言：tonal palette、8dp 网格、Roboto 字阶、Material Symbols、Border+Glow 焦点 | 通过 |
| v4 | hero 改「三卡并排轮播，中间大」 | 用户要求 |
| v5 | 去掉轮播右侧文字栏，只留关键信息；三卡铺满 1152 | 用户要求 |
| v6 | 左竖导航 + 动态背景 | 用户要求 |
| v7 | 用户评「毫无设计感」→ 视觉语言重做：海报进「暗房」 | 否决 v6 |
| v8 | 玻璃浮层（参考 Flix）：大卡 + 右侧两小卡 + Chip 行 + 横排 5 卡 | **当前 Android 界面的基准** |
| v9 | 详情页：去顶栏、左上返回、右栏「也可以看看」 | 已出稿，**尚未落 Kotlin** |

### v8 之后用户逐条修正（都已落地）

1. **「不要有最外面的圆角边框，直接就是背景」** —— 悬浮玻璃面板的圆角 / 描边 / 投影全部删除，`Panel` 退化成空 `Box`，内容直接坐在 `Wall` 色雾上。
2. **「增加两边的距离」** —— 根 padding 从 `horizontal 30dp` 加到 **64dp**，内容宽 1220 → **1152**，所有视图内部 x 坐标同步重算（883 / 728 / 748 等）。
3. **「不要点击就安装，点击之后到详情页」** —— 卡片 `onClick` 从 `Installer.start` 改为 `openDetail(id)`；安装只在详情页右栏按钮触发。
4. **「详情页的横幅放到下面」** —— 详情页由「横幅在上」改为「信息在上、横幅在下」，并让横幅 `weight(1f)` 吃掉剩余高度（固定 250dp 时底部留 155dp 死白）。
5. **「设置中加入修改语言」** —— 新增「界面语言」行（跟随系统 / 简体中文 / English），即 §2 那套不重建 Activity 的方案。
6. **「不用显示导航，左上角显示返回，不显示 logo」** —— 详情页 v9 原型：整条顶栏移除，只留返回胶囊 + 面包屑 + ESC 提示。

## 4. 视觉细节决策（被追问过的那些）

| 现象 | 决策 | 代价 |
|---|---|---|
| 首页大卡留白，图片四周要干净 | 用 `Fit` + 左右羽化 + 边缘色渐变，**不裁图** | 宽高比差异大时仍能看出居中，靠羽化掩盖 |
| 白底 banner 导致背景炭黑 | `vivid()` 提纯：饱和度 0.48–0.78、明度 0.34–0.58，灰色强制换成红/青/蓝 | 部分应用的主色不再"真实" |
| 分类磁贴背景字标太清楚 | 取 32px 缩略图放大（降采样糊） | 真模糊做不到，只能近似 |
| 浅色主题白卡贴白底 | `cardShadow()` **只在浅色**加投影；深色靠描边 + 色雾 | 两套视觉逻辑，改卡片要记得两边看 |
| 详情页横幅占比过大 | 已从固定 250dp 改为 `weight(1f)` 撑满 | `590 = 720-30-70` 改边距要同步 |
| 语言名要不要翻译 | 「简体中文」「English」两端一致，不翻译；只有「跟随系统」跟着翻 | 无 |
| 遥控器怎么选分段控件 | 只有一个确定键，所以 `Seg` 是「点一次跳一档」循环 | 想直接选第三档要点三次 |

## 5. 明确不做的事

- **不做实时爬取 / 在线目录**：目录是 11-11 快照，产品定位是策展入口。要做等于重写上游未开源的管线。
- **不做账号 / 收藏云同步**：「收藏」目前是 0 和 toast 演示，没打算接后端。
- **不做应用截图预览区**：需要真实截图素材，目录里的 `shots` 字段大部分为空。
- **不改 `applicationId`**：已与上游区分，再改会让已装用户变成孤儿。
- **不为了"能装上"放宽签名校验**：`certSha256` + 同包异签检测是安全边界。
