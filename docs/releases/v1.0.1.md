第二个公开版本。品牌视觉统一换新，并补上了应用内自更新。

## 更新内容

- **更名 OpenAPK TV** — 新的「电视 + 绿色笑脸」标识，顶栏、启动页、关于页、TV 桌面横幅统一换新，浅色主题下另有一套深色配色
- **新增关于页** — 版本、许可、数据来源、项目仓库分格呈现
- **下载源可选** — 自动 / 直连 GitHub / 国内镜像三档。默认自动：系统语言是简体中文才走镜像，其它语言直连；系统语言改成简中时会弹窗问一次
- **应用内自更新** — 应用自己检测新版本，不用再回 GitHub 页面
- **视觉与交互** — 卡片去掉 1dp 描边改为填充差分层；分类网格 6 列改 4 列，缩略图变大；浅色主题整体压暗一档；顶栏标识 30dp → 36dp
- **启动更快** — 冷启动改为流式解析 + 二进制缓存，启动页带进度条

## 安装

```bash
adb install -r openapk-tv-1.0.1.apk
```

release 变体（R8 混淆 + 资源压缩），不带 `testOnly`，电视上用 U 盘或文件管理器直接装。从 v1.0.0 覆盖安装即可，签名未变。

- 最低 Android 9（API 28），支持 armeabi-v7a / arm64-v8a / x86
- 体积 3.0 MB

## 已知限制

- 仍用 debug keystore 签名，将来换正式证书时需先卸载再装
- 部分应用的横幅素材自带大号文字，会和主推位标题重叠
